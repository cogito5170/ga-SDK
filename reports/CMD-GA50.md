# CMD-GA50: GA Console 실시간

## Access

The access rules are unchanged: the console still binds 127.0.0.1 only and checks the token and Host/Origin. Open it through the existing SSH tunnel at **http://127.0.0.1:8765/#live**, using the token URL that `ga console` prints. No port was opened and no firewall setting was touched.

## The event stream

Every ga process appends to `~/.ga/events.jsonl`. `GA_EVENTS=<path>` moves the file and `GA_EVENTS=off` turns it off. When `GA_HOME` is set the file is `$GA_HOME/events.jsonl`. Under a test runner with neither variable set, nothing is written.

Prompts, model answers and reasoning are never written. LLM events carry only the state, the model, token counts and seconds.

GA Console's own mailbox polling is quiet, so the console does not flood the stream with its own fetches.

## Notes

- The bridge in this tree runs `ga supervise`, not `ga act` in-process. It hands its AGENT span to the child through `GA_EVENT_PARENT`, so a child ga that emits events hangs under it. The fixture shows the full chain with a fake ga act inside the bridge.
- One regression in the suite was found and fixed before this report: the metadata key `action` collided with the span's own `action` argument (test_ga42_actions).
